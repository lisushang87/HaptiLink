# 电路与制造资料

原理图PDF用于核对网络和引脚，PCB PDF用于布局预览，BOM XLSX用于核对器件，Gerber ZIP用于板厂生产，Altium ZIP用于修改设计。制造前核对这些文件的版本一致性，不能只凭一张照片下单。

当前采集结构：

| 输入 | 复用器 | MCU模拟输入 | 地址选择 |
|---|---|---|---|
| HZ0–HZ5 | U10，6路 | PA0 | PA1/PA2/PA3 |
| H0–H7 | U6，8路 | PB0 | PA5/PA6/PA7 |
| H8–H15 | U7，8路 | PB1 | 与U6共用PA5/PA6/PA7 |

切换地址→等待稳定→ADC采样→打包发送。U10公共端电容100nF，U6/U7公共端10nF，新增通道有24k下拉；源阻抗和电容使高频读数可能未稳定。缩短等待会增加串扰风险。电压范围、供电极性、器件位号以原始原理图为准。

ST-Link通过SWD烧录，USB-TTL/HC-05通过USART1传数据，二者不是同一接口。展示照片见[图片目录](../../doc/pictrue/enhanced/)，AI美化图片不得用作接线依据。
